# Confidence display

AltView’s **Confidence** sidebar destination opens a second output with a prominent local clock and large presented text, or Eucaly’s live projection picture for local media. The clock uses large, bold amber digits centered in a dedicated top band, with a **CURRENT TIME** label and divider. Its display, font, size, alignment and clock format are independent of Audience Design, fullscreen and lower thirds. Next-lyric cues and new scripture integrations remain future work.

1. Connect the confidence monitor by USB-C/HDMI and use macOS extended displays. In AltView, open **Confidence**, choose that display and click **Open Display**. Both output pages use the same numbered monitor menu, **Identify**, **Name…**, **Open Display** and **Close Display** controls. Identify the physical TV, then give it a remembered name such as Stage TV. AltView’s own numbers and names follow the macOS display UUID across discovery reordering and relaunch; they do not claim to match System Settings numbering. A saved assignment reserves that monitor even with its window closed; the other output marks and disables it. Choose another monitor or **Preview Window · no monitor** to free it. Identify briefly labels the selected, unused screen. Selecting the screen containing AltView’s controls asks before covering them.
2. Open **Connections** under **Setup** to pair eucaly and ViewTheWord with this receiver. The same connection feeds Audience and Confidence. When AltView runs on the same Mac, select **This Mac · receiver name**: Bonjour identifies this boot and supplies the listener’s actual current port, then the normal authenticated TLS connection uses loopback. Discovery follows port changes during reconnect even with sender settings closed. This does not restrict AltView’s LAN listener. Remote Macs use ordinary Bonjour/LAN pairing. Manual pairing needs the actual port shown in Connections.
3. Project/show a visible Current lyric slide in eucaly to display primary lyrics. Meaning, translation and transliteration companions remain in eucaly. Explicitly project a verse in ViewTheWord to take text ownership. Confidence shows both selected Bible translations in side-by-side columns, each labelled with its translation name, beneath a shared reference and clock. Audience shows only the primary. A missing or unselected secondary uses the full-width single-translation layout; a missing primary uses the available secondary as the existing single-translation fallback. Opening, focusing, searching, pairing or browsing either app keeps the existing text owner.
4. **Hide Confidence** blanks this output independently of audience Hide/Blank. **Close Display** closes only the confidence window. Restarting Confidence shows the current received text; relaunching AltView keeps saved appearance/display choices and leaves both output windows closed.

Audience Hide/Blank keeps the last presented confidence text readable. Hidden Current navigation keeps the last explicitly presented lyric. Explicit Clear clears Confidence content. Explicitly presenting media replaces the lyrics area with the live projection picture when local capture is enabled. Media follows Eucaly’s audience Hide/Blank, including visible background and overlays; it does not retain the last visible media slide. Hidden navigation does not switch modes. Explicitly showing lyrics returns to readable primary text. A sender’s Stop releases its owned text; AltView’s **Clear & Release** clears the current text owner. Disconnecting the text owner clears its text and never revives a previous app’s lyrics/verse. Reconnect may resume that sender’s retained publication only if output is unowned; taking over another sender still needs an explicit presentation action. Stop/Disconnect cancel pending takeovers and late grants.

Monitor selections persist by macOS display UUID, independently of changing runtime display numbers. Missing monitors stay selected and cannot open until that identity returns. Mirrored or ambiguous identities are rejected. Close an active or waiting output before changing its monitor. A changed monitor identity requires an explicit reassignment; AltView does not guess or copy the old TV’s name to a new identity. Use Identify again after changing cables, ports or adapters. A name can be changed while the output is open without switching its monitor.

Font size is a maximum: long verses shrink to fit fully. The controls report text that fits below 32 points; check readability from the intended viewing distance. The clock comes from this Mac’s local system time/timezone; it does not need either sender or a network clock feed.

Unplugging Confidence closes its window, retains the chosen display identity and waits for that same display to return. It never moves onto another monitor. **Close Display** cancels that restoration. A connected, open output prevents idle system/display sleep; a missing or minimized output releases its own sleep assertion. Pause Receiving clears received text and media while an open Confidence window can continue showing the local clock.

Automated protocol, sender ownership, layout and synthetic screen-lifecycle checks are recorded in [manual validation](manual-validation.md). Physical USB-C/HDMI delivery, unplug/replug behavior across real displays, sleep prevention during a complete service and readability at viewing distance still need the documented hardware rehearsal.

## Local Eucaly media

Run both apps on the same Mac and connect Eucaly through **This Mac · receiver name** (or manual `127.0.0.1` with AltView’s actual port). In Confidence’s **Local Eucaly media** card, turn on **Show Eucaly media**. The card explains setup before enabling, and this explicit action can request Screen Recording permission. If the status says **Permission needed**, click **Open Screen Recording Settings…** and allow AltView. Returning to AltView checks access automatically; macOS may require restarting AltView. Opening Settings never grants permission for you.

The On/Off switch is separate from capture readiness: **Waiting for media**, **Connecting**, **Live**, **Paused** and recovery states say what is happening. **Retry Capture** appears only for stopped capture, retrying failures or a held picture awaiting updates. An empty operator preview explains missing permission, waiting media or a nonlocal source; these messages never appear on the physical Confidence display or cover presented text/media. Browsing Eucaly’s Preview stays private, and audio stays in Eucaly.

AltView remembers whether Local Media is enabled. After relaunch, capture resumes automatically once access is already granted, Eucaly supplies an accepted local media presentation, and Confidence’s preview or output is visible. Output windows still start closed. New installations start with Local Media off; turning **Show Eucaly media** off keeps it off across launches. Launch, pairing and returning from Settings never request permission automatically; missing access shows setup instructions. Capture stopped through macOS still requires an explicit **Retry Capture** within that app session.

Explicitly project an image, PDF, video, webpage or captured-window slide from Eucaly’s Current pane. One shared picture fills Confidence’s main area; lyrics are not shown beside it. AltView’s local clock stays visible above the picture. Eucaly alone runs playback and audio. Preview browsing stays private. Capture targets only the projection window Eucaly reports; it cannot fall back to the library, Preview, Current controls or another app window.

The local-media status reports permission, remote connection, waiting window, live capture and failures. On a remote Mac or macOS 12.0–12.2, Confidence keeps its clock and lyrics support; media has an empty main area and an operator status. Supported capture starts at macOS 12.3. Capture pauses when Confidence is hidden or both its preview and physical output are closed/hidden, then resumes the current accepted source. Closing a physical display while its Confidence preview is visible keeps their shared stream available for the preview. Display disconnect/reconnect uses the existing saved-monitor rules. Clear, Stop, owner disconnect and Pause Receiving clear media. Window recreation and sender reconnect require fresh accepted identity before capture resumes.

The target is aspect-preserving capture within 1920×1080 at up to 60 fps; actual capture rate depends on source changes, macOS and displays. ScreenCaptureKit uses hardware capture/scaling and the picture goes directly from an IOSurface to Core Animation. AltView does not read or copy pixels into CPU images for each video frame. CPU work still includes callbacks, window health checks and UI updates; GPU capture does not imply zero CPU usage. Both preview and output share one capture stream, and an unchanged minute clock does not redraw every second. There is no video network transport or duplicate audio. See [validation and remaining rehearsal checks](manual-validation.md).

Capture pauses while all Confidence canvases are hidden, minimized or occluded, and while the Mac or its displays sleep. It restores the current accepted source when visible again. Resizing or moving Eucaly’s projection between Retina and non-Retina displays updates the stream in place. Still images remain visible through control updates; a blank/suspended capture source clears the picture. If you stop sharing through macOS, capture stays stopped until **Retry Capture**. Transient failures retry automatically with bounded backoff.

Capture setup, start and configuration calls have an eight-second deadline; stopping has a three-second deadline. Retry and shutdown can interrupt pending setup without waiting for macOS to return. Retired frames and errors cannot affect the replacement source, and late setup results are stopped. If several framework calls remain unfinished, further attempts wait for cleanup to free a slot instead of accumulating streams.
