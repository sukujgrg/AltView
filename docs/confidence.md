# Confidence has been retired

AltView’s old Confidence clock, presentation text and same-Mac capture output have
been replaced by **eucaly Media**. eucaly Lyrics (formerly Audience) continues to receive and style text.
Existing monitor assignments are retained for the new media output.

Use [eucaly Media setup](media.md) for the macOS SRT receiver. eucaly and
ViewTheWord keep their own native Confidence output profiles.
